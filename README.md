# 📝 長照身障雙軌補助決策計算器 (PWA 雲端同步版)

> **專為第一線社工與輔具評估人員打造的「智能決策分流與計價系統」。**
> 本系統完美整合 **「長照 3.0 法規」** 與 **「身心障礙輔具補助標準」**，解決實務現場法規交織、額度計算繁瑣、統包與拆分管道抉擇的痛點。

---

## 💡 核心全功能優化特點

1. **雙代碼智慧對照**
   * 試算表底層採用「解耦設計」，同時支援官方長照編碼與身障項次。
   * 免去行政人員自行發明系統代碼的困擾，100% 貼合政府公文格式。

2. **智能差額排序演算法 (分流利器)**
   * 預設加入項目為「暫不申請」之沙盒狀態。
   * 系統自動計算 **「長照補助 - 身障補助」的潛在差額**，並由高至低自動排序。
   * 評估人員只需由上至下依序將差額高者劃分至長照，直到額度用盡，剩下者劃分至身障，即可達成「個案利益最大化」的最佳決策。

3. **雙軌統包模組與單項混搭**
   * 支援輪椅、病床、沐浴椅等強制統包群組，群組上方即時顯示雙軌總計與總差額，並提供一鍵刪除。
   * 精準支援「沐浴椅-M (統包版)」與「沐浴椅 (單項版)」等實務混搭特例，管道切換不互綁。

4. **動態賸餘額度自訂與雙態智慧提醒**
   * 首創「長照剩餘額度」欄位，可依個案歷史進案狀況手動微調賸餘款。
   * **常態模式**：報表下方溫和藍字提醒 `💡 【試算提醒】實際金額以公文為主。`
   * **超額模式**：當長照佔用超越賸餘款，介面與報表同步觸發紅字警告 `⚠️ 【超額警告】長照已超出設定額度，超額需自費。`

5. **模擬桌面高畫質報表截圖 (A4 寬幅比例)**
   * 解決手機螢幕狹窄導致報表被拉長如「超商發票」的 UX 痛點。
   * 截圖下載時，程式會於背景瞬間將報表轉為 700px 寬幅比例並隱藏功能按鈕，產出字體銳利、排版完美的 PNG 格式長圖，方便一鍵轉傳 LINE 給家屬或列印備查。

6. **PWA 全功能手機 App (網路優先離線墊底)**
   * 支援安裝至 iOS (加入主畫面) 與 Android (安裝應用程式) 桌面。
   * 採用 **Network First** 離線快取大腦，有網路時自動檢查 GitHub 獲取最新格式；深入山區、偏鄉等無網路的案家時，App 仍能秒開並流暢進行現場試算。

## 🛠️ 行政人員法規資料庫更新指南

當未來政府補助金額調整、或是新增/刪除輔具項目時，行政人員**完全不需要修改任何程式碼**，只需動 Google 試算表即可。請嚴格遵守以下步驟：

### 第一步：在 Google 試算表上維護資料
請確保您的 Google 試算表結構與格式完全符合以下規範：
1. **數字純淨化**：所有補助金額欄位（一般戶、中低、低收），請輸入純數字（例如 `1200`），**絕對不能帶有千分位逗號**（例如 `1,200`），否則會造成 CSV 檔案解析錯亂。
2. **無給付欄位處理**：若該項目在長照或身障單邊無給付（例如附加功能長照不給付），請**直接留白（空白）**或填寫 `0`。**請勿填寫減號 `-` 或中文**，程式讀取到空白會自動以 `$0` 計算防呆。
3. **單項與統包區隔**：若有像沐浴椅這種需要拆分獨立與統包的項目，統包那列的長照編碼請加上小尾巴（例如 `EA01-2-M`），確保底層 `System ID` 唯一不重複。
4. **長照二組限制**：若該項目屬於長照第二組可給付之項目，請在適用欄位填寫 `Y`；若不給付則留白。
5. **計價特例**：若為固定單項金額（如軀幹側支撐），請在最末欄計價規則填寫 `LTC_FIXED`。

### 第二步：一鍵同步至 App 現場端
1. 確認 Google 試算表的共用權限為：**「知道連結的人，都能『查看』」**。
2. 開啟您的手機/電腦補助決策計算器 App。
3. 確保裝置處於有網路的狀態下，點擊右上方黃色的 **`🔄 雲端更新`** 按鈕。
4. 畫面上會跳出 **「資料同步中，請稍候...」** 的讀取動畫。
5. 動畫消失並顯示 `✅ 同步成功！` 提示後，全台所有評估人員的手機離線資料庫便已全數同步至最新法規狀態！

## 📂 專案檔案架構

* `index.html`：整合 UI 介面、排序計價邏輯、html2canvas 截圖下載以及雲端 CSV 解析引擎之核心主程式。
* `manifest.json`：定義 App 於行動裝置主畫面設定（包含名稱、主題色與圖示路徑）。
* `sw.js`：Service Worker 快取控制器，負責「網路優先、離線墊底」的儲存控制。
* `icon.png`：App 專屬正方形圖示 (建議尺寸 512x512 PNG)。
